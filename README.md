# 📍 Практична робота: Робота з API Geolocation та Інтерактивними Картами (Варіант 6)

## 📌 Загальна інформація
* **Тема:** Створення веб-додатку із застосуванням АРІ-інтерфейсу Geolocation для визначення поточного місця знаходження, трекінгу в реальному часі та взаємодії з картографічними сервісами[cite: 1, 5, 7].
* **Варіант:** №6
* **Технологічний стек:** HTML5, CSS3 (Modern Glassmorphic UI), JavaScript (ES6+ Native API), Leaflet.js (OpenStreetMap)[cite: 1, 7].

---

## 🚀 Функціональність та Структура Роботи

Веб-додаток об'єднує в собі всі три ключові етапи практичної роботи:

### 1. Частина 1. Отримання поточних координат та розрахунки
* **Визначення координат:** Запит до `navigator.geolocation.getCurrentPosition` для виводу широти (`Latitude`) та довготи (`Longitude`).
* **Обробка помилок:** Реалізовано обробник `displayError`, який визначає типи помилок (відмова у доступі, недоступність геолокації, timeout) та виводить коректні сповіщення користувачу[cite: 2].
* **Точність сигналу:** Додано відображення точності визначення координат у метрах (`position.coords.accuracy`)[cite: 4].
* **Розрахунок дистанції:** Обчислення відстані від поточного місця знаходження до координат Коледжу ($48.94321, 24.73380$) за допомогою **формули гаверсинуса**[cite: 3].

### 2. Частина 2. Трекінг координат у режимі реального часу
* **Стеження:** Реалізовано функцію `watchLocation` на основі `navigator.geolocation.watchPosition` для динамічного оновлення координат під час руху.
* **Зупинка стеження:** Кнопка «Clear watch», що викликає `clearWatch(watchId)` та зупиняє моніторинг[cite: 5, 6].

### 3. Індивідуальне завдання (Варіант 6)
* **Інтерактивна карта:** Підключено бібліотеку **Leaflet.js** (альтернатива Google Maps API)[cite: 7]. Карта автоматично створюється та центрується відносно координат користувача[cite: 7].
* **Маркери з інформацією (Popup):** При зміні положення додаються маркери, які при кліку відображають координати та **точний час визначення місцезнаходження**[cite: 7].
* **Пункт призначення та Скрол:** Додано форму для введення координат пункту призначення та кнопку **«Проскролити до призначення»**, яка виконує плавний анімований перехід (`map.flyTo`) до вказаної точки, ставить маркер призначення та з'єднує його з користувачем[cite: 7].
* **Журнал подій (Live Logs):** Динамічний лог дій користувача та статусів системи.
